# Orchestration

This package coordinates WB workflows over managed worktrees, GitHub observations, validation and durable workflow receipts. Managed checkout creation, claims and retirement remain owned by `internal/worktrees` and its domain leaves.

See [LIFECYCLE_BOUNDARIES.md](LIFECYCLE_BOUNDARIES.md) for the source-bound worktree lifecycle analysis, existing reuse, consolidation candidates and proposed extraction order. Its checkpoint and coverage figures are historical; proposed cuts require implementation review.
