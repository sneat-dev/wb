# Contributing to WB

## Issue ownership and routing

Create an issue in `sneat-dev/wb` only when resolving it requires a concrete
change to WB code, tests, documentation, packaging, or release work. Use the
**WB change** issue form, which prompts for the owning repository and the
concrete WB change.

If exactly one other repository must change, create the issue in that owning
repository. If the work spans repositories or concerns Sneat Co. fleet process
or governance, create it in [sneat-co/backstage](https://github.com/sneat-co/backstage/issues/new/choose).

Do not create a WB issue merely to track, mirror, or expose work owned by
another repository. Routing is guidance, not automated enforcement: a misrouted
issue is closed by a maintainer with a pointer to the repository that owns it.
